# SWYNEX Exploratory Data Analysis

## Project Overview

This project was completed as part of my **SWYNEX Technologies Data Analyst Internship**.

The objective of this task was to perform **Exploratory Data Analysis (EDA)** on a cleaned marketing campaign dataset to understand customer characteristics, purchasing behavior, campaign response, trends, patterns, and potential anomalies.

## Dataset

The dataset contains **2,240 customer records and 27 columns** after the data cleaning process.

The dataset includes information related to:

* Customer demographics
* Income
* Recency
* Product spending
* Web purchases
* Catalog purchases
* Store purchases
* Campaign responses
* Website visits
* Customer complaints

## Tools Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn

## EDA Performed

The following analysis was performed:

1. Dataset structure and dimensions
2. Descriptive statistics
3. Average income and purchase behavior
4. Customer response analysis
5. Education-level analysis
6. Income distribution
7. Product-category spending analysis
8. Purchase-channel analysis
9. Correlation analysis
10. Outlier/anomaly analysis

## Key Results

* The cleaned dataset contains **2,240 rows and 27 columns**.
* No missing values remained after the cleaning process.
* No duplicate rows were found.
* Average customer income was approximately **52,237.98**.
* Average recency was approximately **49.11 days**.
* Average web purchases were approximately **4.08**.
* Average store purchases were approximately **5.79**.
* Average catalog purchases were approximately **2.66**.
* The campaign response rate was approximately **14.91%**.

## Conclusion

The exploratory data analysis helped identify important patterns in customer demographics, purchasing behavior, product spending, purchasing channels, and campaign responses.

The analysis and visualizations provide a better understanding of the dataset and can be used as a foundation for further dashboard development and business analysis.
